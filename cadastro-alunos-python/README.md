# Sistema Escolar em Python

## Sobre o projeto

Sistema escolar desenvolvido em Python para realizar o cadastro de alunos, lançamento de notas e acompanhamento da situação acadêmica.

O projeto utiliza Programação Orientada a Objetos (POO), funções e estruturas de dados para organizar e gerenciar as informações dos alunos.

## Funcionalidades

- Cadastro de alunos com nome, idade e matrícula.
- Validação dos dados informados.
- Lançamento da primeira e segunda notas.
- Lançamento de nota de recuperação.
- Cálculo da média inicial e final.
- Verificação da situação acadêmica (Aprovado, Reprovado ou Em andamento).
- Consulta dos dados e notas dos alunos.

## Tecnologias utilizadas

- Python 3.14
- PyCharm

## Como executar

1. Clone este repositório.
2. Abra o projeto no PyCharm ou na sua IDE de preferência.
3. Certifique-se de possuir o Python 3.14 instalado.
4. Execute o arquivo principal do projeto.

## Objetivo

Projeto desenvolvido com o objetivo de praticar conceitos de Python, Programação Orientada a Objetos, validação de dados e estruturas de controle.
